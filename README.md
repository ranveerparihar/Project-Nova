🚀 Project NOVA

A simple text-based adventure game built in Python, created to practice Python fundamentals while building something interactive.

You play as an infiltrator attempting to enter Nexus Corporation, reach the NOVA CORE, and shut down the facility before the reactor overloads.

🎮 Current Features
🏢 Main Gate exploration
🔐 Security terminal and access codes
❤️ Health system
🪙 Token system
🚨 Security alert system
🛣️ Choice-based gameplay
💀 Game-over conditions
⌨️ Interactive user input
⏳ Typewriter-style text effects
🐍 Python Concepts Practiced
Dictionaries
if / elif / else
while loops
for loops
Variables and data types
User input
Assignment operators
Basic game logic
time module
